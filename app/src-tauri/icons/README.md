# Icons

Generated from `source.png` with `npx tauri icon src-tauri/icons/source.png`, run
from `app/`. Regenerate rather than editing a size by hand.

`source.png` is a placeholder drawn from the draft palette in spec.md Appendix C
(gold `#FEBE10` on `#1A1A1A`): a keycap outline with a filled travel bar. It is a
stand-in until the product has a real identity, and the product name itself is
still an open question, so nothing here should be treated as branding.

The Android and iOS sets that `tauri icon` also produces are deleted on purpose:
this is a desktop product, and mobile is explicitly out of scope.
