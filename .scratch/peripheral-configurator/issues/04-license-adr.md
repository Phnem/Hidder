# TICKET-04: Зафиксировать лицензию проекта

## Status

DONE

## Objective

Зафиксировать лицензию проекта в `LICENSE` + `docs/decisions/0001-license.md` (ADR-формат), закрыв блокирующий вопрос §17.1 плана.

## User or system value

Разблокирует все последующие тикеты, которые касаются заимствования кода/фактов из GPL-проектов (sharkfin, OpenRGB, OpenRazer) — без этого решения TICKET-01/03/09 не могли бы сформулировать правило "что можно, что нельзя".

## Dependencies

Нет.

- `docs/decisions/0001-license.md` по шаблону ADR (§19.2 плана): контекст, варианты, решение, последствия.

- Лицензия для device-данных сообщества — вынесена в открытый вопрос Q1 в `spec.md`, не блокирует этот тикет.

## Deviations

- Planned: тикет должен был исполняться в рамках Phase 8 (implementation loop).

- Reason: решение по лицензии — блокирующий вход для формулировки правил заимствования кода/фактов во всех остальных тикетах Phase 0.
- Consequence: нет отрицательных последствий — работа чисто документационная, не код продукта; не нарушает "one ticket at a time" для кода.
- Follow-up: нет.
